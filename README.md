# GrillMaster POS - iCET Coursework

A responsive Web-based Point of Sale (POS) system designed and developed for a fast-food burger shop.

## Built With
* HTML5
* CSS3
* Vanilla JavaScript

## Features
* Burger, Fries, and Drinks ordering with real-time bill calculations
* Customer Management (CRUD)
* Item Management (CRUD)
* Order Management & History
